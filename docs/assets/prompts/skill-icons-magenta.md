# Starting Skill Icon Prompts v2

These are the six Codex built-in image-generation briefs accepted on 2026-07-29.
Every request used a square canvas, one centered isolated hand-painted fantasy party-game
object, a chunky readable silhouette, strong highlights, no text or frame, and generous
padding. Five requests used a flat chroma-key green background and Aegis used flat
chroma-key magenta. The backgrounds were removed locally and the results were normalized
to 256×256 RGBA PNGs.

The palette is intentionally role-based rather than uniformly cyan: violet movement,
gold projectile, crimson control, orange impact, blue-white zone, and emerald-gold defense.

## Blink Step / 잔상 회피

Create a premium fantasy game skill icon of a single dark violet leather adventurer boot
cutting sharply sideways through bright lavender-white afterimage streaks. Use a compact
three-quarter silhouette, silver buckles, deep purple shadows, and a clear sweeping motion
arc. Keep it readable at 64 pixels. No text, border, badge, floor, cast shadow, or extra
objects. Isolate it on a perfectly flat chroma-key green background.

## Arc Bolt / 파동탄

Create a premium fantasy game skill icon of one dense golden lightning bolt exploding from
a bright white-yellow core and pointing toward the upper right. Use thick orange-gold
branches, dark navy edging, a compact projectile silhouette, and short sparks that remain
inside generous padding. It must read as a damaging ranged projectile, not a logo. No text,
border, badge, or scenery. Isolate it on a perfectly flat chroma-key green background.

## Chain Bind / 사슬 속박

Create a premium fantasy game skill icon of thick blackened iron chains snapping shut around
a glowing crimson-magenta binding core. Make a circular trapped silhouette with heavy links,
hot red cracks, bright pink-red energy, and dark metal contrast. It must instantly communicate
immobilization. No text, border, badge, loose rope, or scenery. Isolate it on a perfectly flat
chroma-key green background.

## Meteor Mark / 낙석 표식

Create a premium fantasy game skill icon of a burning volcanic meteor descending onto a
bright engraved orange targeting rune. Use a compact vertical composition, black cracked
rock, molten orange fissures, a short flame tail, and a distinct circular impact mark below.
No text, border, badge, smoke cloud, or scenery. Isolate it on a perfectly flat chroma-key
green background.

## Frost Field / 빙결 지대

Create a premium fantasy game skill icon of a persistent frozen ground field: one circular
cracked ice platform with several large blue-white crystal spikes. Use luminous cyan edges,
deep cobalt interiors, white frost, and a broad stable silhouette that reads as an area on the
ground. No snowflake logo, text, border, badge, or scenery. Isolate it on a perfectly flat
chroma-key green background.

## Aegis / 수호 방패

Create a premium fantasy game skill icon of a stout emerald-green shield with a thick worn
gold rim and a faceted glowing green mana crystal in the center. Use a frontal three-quarter
view, bright lime highlights, dark green shadows, and a simple protective silhouette. No text,
border, badge, character, cast shadow, or scenery. Isolate it on a perfectly flat chroma-key
magenta background.
